## 一、产品定位

**一句话定位**：一个用真实市场行情，对 6 套量化策略进行"每日模拟交易 + 全流程可视化监控"的看盘与复盘工作台。

它处在两个极端之间：

- 它**不是实盘下单软件**：不接券商、不下真单、不碰真实资金；
- 它**也不是纯历史回测工具**：不是拿过去的数据算一个静态成绩，而是每个交易日用当天真实行情，让策略"真的买卖一遍"。

它的本质是一&#x53F0;**"真实行情驱动的纸面交易监控台"**：行情是真的，交易是模拟的，账本是连续的。

### 产品要守住的三件事

1. **行情真实**：每日数据来自真实市场，绝不能编造、不能拿旧数据冒充今天、不能用回测结果冒充每日战绩；
2. **账本连续**：每个策略从上线第一天起，盈亏一笔一笔累加，形成一条不可篡改的成长曲线；
3. **一眼看清**：用户打开面板，几秒内就能看清每个策略今天做了什么、赚了还是亏了、长期表现如何。

| 四级           | 面板好管理       | 各个板块边界清晰，可方便地上下移动、增加、删减           |

## 三、产品边界（做什么 / 不做什么）

**产品做：**

- 每个交易日按 6 套策略规则，在真实行情上模拟买卖；
- 记录每个策略的持仓、现金、当日盈亏、累计盈亏、参赛天数；
- 展示策略卡、今日交易、收益曲线、过拟合审计、风险指标、变更日志；
- 自动检测数据异常并就地告警；
- 提供买卖记录、对账单、盈亏历史、盘后复盘等台账。

**产品不做：**

- ❌ 不真实下单、不碰真钱；
- ❌ 不生成任何假行情、假盈亏；
- ❌ 不用历史回测成绩冒充每日模拟成绩；
- ❌ 不在缺数据时用前一天数据"假装今天也有"；
- ❌ 不提供投资建议，所有数字仅为策略模拟结果。

## 四、目标用户与使用场景

### 4.1 用户角色

| 角色        | 关心什么                      |
| --------- | ------------------------- |
| 策略主人（主用户） | 今天 6 个策略买卖了什么、赚亏多少、长期谁强谁弱 |
| 运营/盯盘角色   | 系统今天跑没跑、数据新不新、有没有断更       |
| 测试/核对角色   | 数字真不真、改动有没有破坏历史成绩         |
| 产品/技术维护角色 | 板块能不能安全调整、出问题能不能回滚        |

### 4.2 核心场景

1. **收盘后例行看盘（最高频）**：看组合整体 → 扫 6 张卡今日动作 → 点开关心的策略看完整规则与持仓 → 看曲线对比。
2. **盘中盯信号**：看今天哪个策略发出买卖信号、目标是什么、等待成交。
3. **复盘某笔交易**：查某策略某天的成交价、数量、盈亏。
4. **评估策略含金量**：看过拟合审计、参数稳定性、A/B 对照，判断高收益是真本事还是参数碰巧。
5. **异常排查**：看到卡片红色告警 → 看首次发现日期和原因 → 处理。
6. **手机快速查看**：移动端看精简卡片，需要时点"展开详情"。

- 面板至少保留 3 个可见板块，避免被清空。

## 六、策略产品规格

### 6.1 六个策略总览

每个策略独立账户、**统一 1 万元起始本金**、从各自上线首日开始模拟。

| 策略         | 类型          | 标的范围                 | 风格                       | 历史回测参考（仅回测口径）                       |
| ---------- | ----------- | -------------------- | ------------------------ | ----------------------------------- |
| **七星策略**   | 创业板动量       | 11 只 ETF（含货币防御 ETF）  | 单持仓、看市场广度                | 近 2 年年化约 +32% / 夏普 1.9 / 胜率 65%     |
| **三驾马车**   | 行业轮动棘轮      | 约百只 ETF 池，持有 5 只等权   | 动量+宽度+止损三策略并行、半月调仓       | 近 2 年年化约 +38% / 夏普 1.8              |
| **追电策略**   | 跨境 ETF 动量轮动 | 11 只跨大类 ETF，评分前 38   | 短周期、爆发力强、带熊市过滤           | 近 2 年年化约 +103%（同期最强）                |
| **三合策略**   | 多策略融合       | 5 只 ETF + 三套信号投票     | 波动率倒数加权、兼顾牛熊             | 近 2 年年化约 +25% / 夏普 1.4              |
| **闪电策略**   | 3 日动量短线     | 4 只跨境科技 ETF          | 单持仓、快进快出、硬止损 -7%/止盈 +5%  | 近 2 年年化约 +27% / 回撤 -14%             |
| **黄金组合 A** | 恐慌反转模型      | 5 ETF + 3 股票 + 5 可转债 | DMA 金叉、三重过滤、低频（21 笔/5 年） | 近 5 年 +4.5% / 回撤 -8%，2026-09-21 起模拟 |

> 回测数字仅代表历史回测，**不等于**每日模拟实盘成绩，两者在面板上严格分区、不得混用。

### 6.2 策略卡（每个策略一张卡）

策略卡是一个策略的"仪表盘"，自上而下包含：

| 区域           | 展示内容                                   |
| ------------ | -------------------------------------- |
| **顶部标签（可点）** | 策略版本名、数据期、一句话口径                        |
| 状态徽章         | 运行中（绿）/ 未启动（灰）/ 数据告警（红或黄）              |
| 今日动作         | 买入 / 卖出 / 持有 / 空仓 + 目标标的（如"观望 513520"） |
| 核心指标         | 当前市值、总盈亏、收益率（%）、今日盈亏、参赛天数              |
| 迷你净值图        | 该策略实盘模拟净值小图，可点开大图                      |
| 仓位现金         | 持仓明细、可用现金；空仓时显示"空仓观望"                  |

**卡片数字口径（业务规则）：**

- 当前市值 = 1 万本金 + 累计盈亏；
- 收益率 = 累计盈亏 ÷ 1 万 × 100%，统一用百分比、保留 2 位小数；
- 空仓时，历史利润已落袋为现金，市值仍应等于"本金+累计"，不能因为空仓就归零；
- 卡片数字必须来自真实数据，**禁止写死任何数字**。

### 6.3 策略详情弹窗（点顶部标签弹出）

**形态**：纯文字、从上到下、每个属性独占一行，完整呈现 **8 段策略详情**：

1. **版本名称**：当前版本号与命名；
2. **标的筛选**：买什么范围、怎么筛选排序；
3. **买入规则**：什么条件触发买入；
4. **卖出规则**：什么条件触发卖出；
5. **止盈止损**：止损线、止盈方式、回撤约束、成交制度；
6. **牛熊针对**：是否有熊市过滤、是否做过跨周期验证；
7. **回测数据**：2 年/5 年回测年化、夏普、回撤、胜率、交易笔数（明确标注"回测"）；
8. **其他特点**：本金、持仓数量、权重、基线说明。

弹窗还包含：实盘模拟核心指标（市值/累计盈亏/收益率/今日盈亏/参赛天数）、仓位与现金、持仓明细。  
**不允许**：弹窗打不开、点了没反应、满屏"--"。

## 七、主面板各板块功能规格

### ① 投资组合摘要（顶部）

回答"6 个策略加起来现在多少钱、整体赚了多少"。

- 展示：组合总资产、总盈亏、总收益率（%）、模拟起始日、在跑策略数；
- 只统计已经开始每日模拟的策略；未启动的策略不计入总资产和分母；
- 起始日必须真实，不能写死。

### ② 今日交易·模拟盘

- 标题明确标注"模拟盘（非实盘）"；
- 展示当天每个策略的买卖动作、目标标的、目标仓位，以及当前持仓；
- 是盘中盯信号、收盘看成交的核心区。

### ③ 策略卡板块

见 6.2 / 6.3，6 张卡网格排列。

### ④ 收益对比曲线

- 支持切换看 **近 2 年回测 / 近 5 年回测 / 实盘模拟** 三条口径；
- 可叠加对比多个策略净值；
- **实盘模拟曲线只连真实交易日**：没有真实数据的日子留空、不画点，不得拿回测曲线接在实盘曲线后面。

### ⑤ 每日盈亏趋势

- 展示各策略最近 14 天每天赚亏多少的柱状/折线趋势，可切换查看方式。

### ⑥ WFA 滚动前推过拟合审计

- 用滚动前推方法检验策略参数是不是"过拟合碰巧有效"；
- 展示健康度卡片 + 样本外盈亏曲线；
- 明确标注"回测/样本外"口径。

### ⑦ 参数稳定性监控

- 展示策略参数在多个历史训练窗口中的分布；
- 参数频繁漂移 = 策略可能不稳，给出直观提示。

### ⑧ A/B 对照

- 对照"优化后参数"与"原始参数"的实际表现，验证优化到底有没有带来超额收益；
- 展示对照 KPI、对照卡片、差值趋势。

### ⑨ 风险监控

- 展示最大回撤、夏普比率、波动率等风险指标；
- **当前为待建设板块**（位置已预留）。

### ⑩ 策略变更日志

- 按日期记录策略每次版本迭代（棘轮升级）与盘后复盘；
- 支持按日期查看、按区间查询、记录复盘笔记。

## 九、交易与成交业务规则

### 9.1 信号与成交节奏

- 每个交易日分两步：**收盘后决策**（用当天行情算买卖信号）与**成交执行**（在真实价格上模拟成交）；
- 交易窗口内每隔约 10 分钟做一次幂等检查，已成交、非交易日、非交易时段都直接跳过，不重复成交。

### 9.2 行情来源容错（业务规则）

- 行情按 **东方财富 → 腾讯 → 新浪** 三个来源依次尝试；
- **只要任一来源能拿到当天真实价，就必须成交/补成交**；
- 只有三个来源全部失败、确实拿不到真实价时，才允许暂停并亮红灯等待人工。

### 9.3 补单规则（重要，2026-10-10 权威确立）

1. A 股 15:00 收盘后，现价即当天收盘价，下午、傍晚都可补当天成交，**不存在"17 点后不能补单"的截止线**；
2. 行情拿不到时，按约 10 分钟节奏持续重试（前几轮 2/3/5 分钟退避，之后固定 10 分钟），直到拿到真实价；
3. **绝不用旧价成交、绝不伪造、绝不因为一时拿不到价就判定当天不交易**；
4. 跨日发现漏单：只要能取到漏单当天的真实收盘价，就按该真实价补记，并明确标注"事后补记"；
5. 只有连历史真实收盘价都彻底取不到（理论上几乎不可能）才常亮红灯、等人工。

## 十、账本与数据的业务规则（核心金融口径）

### 10.1 累计盈亏是"历史账本"，不是普通数字

- 累计盈亏 = 从上线第一天起，每天盈亏一笔一笔累加的结果（类似银行流水余额）；
- **今天累计 = 昨天累计 + 今天盈亏**，不能每天从零重算；
- 今天数据缺失或不可信时，**保持昨天累计不变**，不能用 0 或随机数顶替；
- 未经用户明确许可，**不得修改、覆盖任何历史累计成绩**。

### 10.2 资金恒等式（每个策略每天都必须成立）

> **现金 + 持仓市值 = 本金 + 累计盈亏**

- 持仓时：现金 + 手里证券市值 = 本金 + 累计盈亏；
- 空仓时：手里没证券，历史利润已落袋，**现金 = 本金 + 累计盈亏**；
- 等式不成立即为数据错误，必须告警。

### 10.3 收益率口径

- 所有收益率统一用**百分比**（如 151.42 表示 +151.42%），保留 2 位小数，禁止小数形式（如 1.51）；
- 字段含义、单位、精度、累计方式一经确定，不得中途更改；如要更改须说明影响、给出迁移方案并经用户许可。

### 10.4 回测与实盘严格分离

- 回测只用于打磨策略参数，每日模拟只来自当天真实行情，两者不得互相拿数字填充；
- 不允许在实盘盈亏为 0 时，用回测收益率折算一个"等效实盘成绩"；
- 回测的本金、交易笔数、夏普、回撤不得出现在实盘数字的位置上。

### 10.5 未启动策略留空

- 尚未开始每日模拟的策略（如黄金组合 A 上线前）：显示灰色"未启动"徽章，所有实盘数字留空/为 0，不计入组合总资产与策略数；
- 不得用回测数字先占着实盘位置。

### 10.6 交易日连续

- 每个在跑策略在真实交易日都应有数据，做到**不缺天、不空文件、周末不误跑**；
- 补齐历史缺口必须用"当前上线参数 + 固定 1 万本金 + 真实历史行情"重算，并核对累计末值一致。

## 十一、数据告警产品体验

### 11.1 就地标注原则

**哪个位置的数据错了，就在那个位置直接标出来**，而不是另开一个告警页让用户自己找：

- 错误：红色背景 + ❌ + **首次发现日期**；
- 警告：黄色背景 + ⚠️ + 首次发现日期；
- 鼠标悬停可看完整错误说明；标注带呼吸闪烁以引起注意；
- **问题不修，标注不消失**；修复并复检通过后自动取消。

### 11.2 告警覆盖范围与类型

覆盖**全部 6 个策略、逐个扫描**：

| 告警       | 含义                 | 严重度       |
| -------- | ------------------ | --------- |
| 资金恒等式不成立 | 现金+持仓 ≠ 本金+累计盈亏    | 错误（红）     |
| 本金不匹配    | 本金不是统一的 1 万元       | 错误（红）     |
| 盈亏异常归零   | 累计盈亏异常为 0、市值贴近本金   | 警告（黄）     |
| 数据陈旧     | 多日没有新数据（超过 5 个交易日） | 警告（黄）     |
| 现金为负     | 账户现金出现负数           | 错误（红）     |
| 出现假数据    | 数据来源含模拟/伪造标记       | 错误（红，最高级） |
| 数据缺失     | 当天应有数据却没有          | 错误（红）     |

### 11.3 告警生命周期

首次发现记录"首次发现日期"；持续存在则每天更新"最后发现日期"但保留首次日期；问题修复后告警自动清除、页面标注消失。

## 十三、产品铁律（不可妥协）

1. **策略规则是核心资产**：策略买卖逻辑只有在有明确、针对性的理由并经许可时才能改，禁止"顺手优化/重命名/整理"。
2. **永久禁止假数据**：任何异常都不能成为编造行情或盈亏的理由；出错就报错/用缓存并标注陈旧/保持上一天数据。
3. **收益率统一百分比**。
4. **展示与算法口径与历史保持一致**：长期项目，数据一致性是核心价值，不得中途改口径。
5. **不覆盖历史累计成绩**：历史账本不可改，批量重建必须先备份并经许可。
6. **策略详情弹窗必须可用**：点顶部标签必须能看到完整 8 段详情。
7. **禁止旧数据冒充当天、回测冒充实盘、未启动先占位；交易日数据必须连续。**
8. **成交只认真实价**：三源任一可得即成交，持续重试，跨日可按真实收盘价补记。

> 违反第 2、5、7 条属于最高级事故，必须立即停止、回滚、根因复盘并留档。

## 十四、当前已知产品问题（登记待修，截至 2026-10-10）

### 问题 1（P0）：空仓时总资产显示失真、持续红色告警

- **现象**：5 个在跑策略当前全部空仓，历史利润其实已落袋，但空仓时"现金"被显示为 0，导致资金恒等式左端为 0，面板总资产/市值被错误压低，并从 2026-09-30 起持续报红。
- **正确表现**：空仓时现金应等于"本金+累计盈亏"，例如追电空仓但历史赚了 15,141.93 元，现金/市值应显示 25,141.93 元。
- **常见疑问解答**："为什么空仓很久、收益率却很高？"——不矛盾。收益率是历史累计成绩，空仓只代表当下没持仓，前期利润已卖出落袋；真正的缺陷是空仓时现金没把这笔利润体现出来。
- **修复要求**：从数据源头修，不改历史累计盈亏，修后资金恒等式成立、红色告警自动消失。

### 问题 2（P1）：追电策略内部账本仍按旧 10 万本金口径

- **现象**：其余策略均已统一为 1 万本金，唯独追电的每日交易底层记录仍残留早期 10 万本金口径，与面板展示的 1 万口径不一致，存在后续对账/曲线算错的风险。
- **修复要求**：统一为 1 万本金，回填前备份并经许可，修后各处本金与累计成绩对得上。
