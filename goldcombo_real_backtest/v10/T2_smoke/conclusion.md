## 3. 关键发现: V10 高价股不交易的设计特性

**根因**: V10 内置 sizing 逻辑
```python
cash_to_use = self.broker.getcash() * self.p.per_pos_pct  # 10000 × 0.20 = 2000
size = int(cash_to_use / (price * 100)) * 100  # 1 手 = 100 股
```

| 股票 | 价格 | 1手成本 | 2000元能买多少手 | int → ×100 → 股数 |
|---|---|---|---|---|
| 茅台 | 1148+ | 114,800+ | 0.017 | 0 → **0 股** |
| 海康 | 23-48 | 2,300-4,800 | 0.42-0.87 | 0 → **0 股** |
| 通威 | 10-64 | 1,000-6,400 | 0.31-2.0 | 0/1/2 → 0/100/200 股 |

**这是 V10 设计特性, 不是 bug**:
- V10 严格要求 1 手 (100 股) 起买
- 单票 20% 现金 (2000元/股 for 10000元账户)
- 单价 ≥ 10元 时, 2000元 才够买 1 手
- 单价 < 10元 时, 可买 2 手+
- 单价 ≥ 23元 时, **任何账户都买不起 1 手**

**含义**: V10 实际只交易 **低价股 (price < 20 元)**。在 1950 只沪深池中, 这部分股票占比估计 30-40% (主要为低价中小盘)。
