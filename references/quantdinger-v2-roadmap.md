# Quant Monitor V2 演进路线图

> 对标 QuantDinger 的 v2 演进路线，从本地单机监控向双端协同演进。

---

## 当前架构

```
┌─────────────────┐     ┌─────────────────┐
│   macOS (开发)   │     │  Windows (实盘)  │
│  设计/开发/调试   │     │  QMT/xTQuant    │
│  数据分析/诊断    │     │  实盘交易运行    │
└────────┬────────┘     └────────┬────────┘
         │                       │
         │   work_logs 同步      │
         │◄──────────────────────│
         │                       │
┌────────▼───────────────────────▼────────┐
│         Flask :8000 监控面板            │
│  6策略 · 模拟盘 · Tailscale 远程访问    │
└─────────────────────────────────────────┘
```

---

## 已完成 (v1.3.0)

### 核心功能
- [x] 6策略监控面板（七星/三驾/追电/三合/闪电/黄金组合A）
- [x] 实时行情（腾讯财经 API）
- [x] 收益曲线 / 买卖记录 / 对账单 三个子页面
- [x] 模拟/实盘数据切换（localStorage 持久化）
- [x] 数据真实性标注（模拟盘非实盘）
- [x] 多策略组合总览（总资金/总收益）

### 数据层
- [x] work_logs → signals JSON 每日重建
- [x] 新旧引擎收益率衔接
- [x] 引擎重置自动检测（>50% 跳变）
- [x] 旧格式空文件过滤
- [x] 内存缓存层（423 信号文件启动加载）
- [x] 子页面后端筛选 API（策略/日期/动作）

### 前端
- [x] 公共层 common.css / common.js
- [x] 策略卡红色"模拟盘"徽章
- [x] 顶部模拟/实盘切换按钮
- [x] 暗黑主题响应式布局
