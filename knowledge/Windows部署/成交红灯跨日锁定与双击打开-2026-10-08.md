# 成交红灯跨日锁定 + 双击打开面板（2026-10-08）

适用：AI量化监控（模拟盘，本机真实撮合，不接任何券商账号）。Mac 设计制作、Windows 实盘运行、GitHub 中转；Windows 仅交易日 13:00–17:00 开机。

## 一、双击打开面板
- 后台在运行时，**直接双击项目里的 index.html** 就是面板（file:// 已自适应连本机 8000）。
- 后台没运行时，双击一键启动器：Mac `启动AI量化面板.command`；Windows `启动AI量化面板.bat`（纯 ASCII，自动起服务+开实盘页，无需敲网址）。
- Windows 上启动器随每日 git pull 自动到位，无需重跑安装器。

## 二、成交红灯（红标）是什么
- 交易日 13:00–17:00，监督器对东财→腾讯→新浪三源持续重试取真实价；**绝不用历史旧价成交**。
- 到 17:00 仍极端失败（三源持续全失败，理论上不应发生）：落下持久红标，面板顶部亮红灯。
- **红标一旦亮起：次日及以后（含周末/节假日）都不再自动成交、绝不自动补单，红灯一直亮。** 即使 Windows 当天没开机，红标经 GitHub 同步，Mac 面板仍恒红。

## 三、人工如何处理红灯（唯一解除方式）
1. 人工核对行情与账本，确认问题原因、账目无误。
2. 在项目目录运行（Windows 用 venv 的 python，Mac 均可）：
   ```
   python scripts/ack_trade_redflag.py            # 解除并上传，面板灭灯
   python scripts/ack_trade_redflag.py --status   # 只查红灯状态
   ```
   或 `python trade_supervisor.py --ack-redflag`。
3. 解除后从**下一交易窗口**恢复自动成交；**被红灯冻结的那一天不补单**（避免隔日资金口径错误）。
- 系统没有任何自动解除 / 自动跨日补单路径。
