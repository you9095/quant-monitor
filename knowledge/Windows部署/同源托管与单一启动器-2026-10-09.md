# 同源托管与单一启动器（2026-10-09 换方向后的标准形态）

> 适用：AI 量化监控面板在 Windows（实盘运行，D:\quant-monitor）与 macOS（设计调试）的启动与访问。
> 本文取代此前"双击 index.html + quant:// 协议启动"的所有做法。

## 一、最终形态（记住这一句）
**起一个本地 Flask 服务，浏览器访问 `http://localhost:8000/`，前端和接口同源；用户只双击桌面一个"AI量化面板"图标。**

- 后端：`api/real_data_server_v2.py`，监听 `0.0.0.0:8000`，既提供 `/api/v1/*`，也同源托管前端页面与 assets。
- 启动器：`scripts/launch_panel.py`，所有入口（桌面图标、计划任务、更新脚本、Mac .command）统一调它。
- 用户入口：Windows 桌面快捷方式"AI量化面板"（pythonw 无黑窗）→ 后台没起就静默拉起，就绪后自动打开 `http://localhost:8000/`；后台已起则直接开页面。

## 二、为什么不能再用双击 index.html / 网页按钮启动
1. `file://` 页面 fetch `http://localhost` 属于私有网络访问（PNA），桌面 Chrome/Edge 真机拦截，headless Chrome 不复现桌面策略，实验室通过真机失败。
2. 网页按钮经 `quant://` 自定义协议 + 注册表 + 隐藏 iframe 拉起本机程序，会被浏览器拦截、窗口一闪即退、且不回跳；普通权限注册脆弱。
3. 这两条都是浏览器安全红线，打补丁无解，必须换成同源 HTTP。
4. file:// 现仅保留为后备：Mac 桌面 Chrome 可直连；Windows 以桌面图标 → http 为准。遮罩绿色按钮改为**顶层跳转** gotoPanel()（顶层导航不受 PNA 限制）。

## 三、启动器 launch_panel.py 行为
- 幂等：先 GET `/api/v1/health`，已在运行：带 `--open` 直接开浏览器，不带 `--open` 直接退出。
- 未运行：用同环境解释器 DETACHED + 无窗拉起 real_data_server_v2.py（-u），stdout/stderr 追加 `logs/backend_boot.log`；文件锁 `logs/launch_panel.lock` 防并发多开。
- `wait_healthy()` 轮询最多 90 秒；`--open` 就绪后 open_in_browser（Windows os.startfile / Mac open / Linux xdg-open）。
- 失败：Windows 用 ctypes MessageBoxW 弹明确错误并指向日志，绝不静默闪退。
- 守护计划任务 QuantPanelGuard 调 `launch_panel.py`（**不带 --open**），只保活不抢焦点、不弹浏览器。

## 四、Windows 桌面图标如何产生（自动，无需手建）
- 后端启动时 `win_self_register.self_register_if_windows()` 普通权限自注册：quant 协议（后备）、QuantPanelGuard 计划任务、桌面快捷方式。
- 桌面快捷方式 `_create_desktop_shortcut()`：PowerShell `-EncodedCommand`（UTF-16LE base64）传中文，规避 GBK 批处理乱码；Target=pythonw.exe，Arguments=`launch_panel.py --open`，WindowStyle=7，幂等。
- 结果写 `logs/self_register.log`（desktop-shortcut=ok/fail）。

## 五、更新代码（GitHub 中转，不人肉打包）
- 代码仓库 `github.com/you9095/quant-monitor` master；数据仓库 `quant-monitor-live-data` master（唯一数据真相源）。
- `update-and-start.bat`：git fetch + `reset --hard origin/master` → taskkill 8000 → venv python launch_panel.py --open；失败 pause 并指向 logs。**纯 ASCII、CRLF**。
- 自动：Windows 仅交易日 13:00–17:00 开机；QuantBootCheck（登录+1min）、QuantDailyTrade（登录+3min，含 git reset、装依赖、trade_supervisor、push、心跳、重启面板）会自动拉新。
- 手动立即更新：双击一次 update-and-start.bat（旧版也行，第一步就拉新），完成后桌面出现图标，以后只双击图标。

## 六、静态托管安全白名单（防账本/源码泄露）
- 服务监听 0.0.0.0（同网段可达），故静态路由必须白名单：
  - 可访问：6 个前端 html、`assets/` 白名单扩展名（.html/.js/.mjs/.css/.json/.png/.jpg/.gif/.svg/.ico/.webp/.woff2/.ttf/.eot/.map/.txt，排除 .bak）、favicon。
  - 禁止：api/ scripts/ live-data/ .git/ venv/ strategies/ signals/ data/ config/ tests/ memory/ work_logs/ project_memory/ knowledge/ docs/ references/ audit/，以及任何含 `..` 的路径 → 404。
- 教训：无白名单 catch-all 曾 200 暴露 real_data_server_v2.py、launch_panel.py、live-data 账本 json、.git/config、venv 配置。

## 八、排障速查
- 页面"数据后台没有运行"：先看后台是否在（访问 http://localhost:8000/api/v1/health）；不在就双击桌面图标或 update-and-start.bat，看 logs/backend_boot.log。
- bat 黑窗一闪/乱码：文件必须纯 ASCII + CRLF（UTF-8 中文会被 GBK cmd 截断，是 V1–V8 闪退根因）。
- 端口占用：update-and-start.bat 会 taskkill 8000；launch_panel 有锁防多开。
- Mac launchd：`launchctl list | grep ai.quant.flask`；last exit -9 多为 kickstart -k 或任务清理进程组，非崩溃，KeepAlive 会自动重拉。
