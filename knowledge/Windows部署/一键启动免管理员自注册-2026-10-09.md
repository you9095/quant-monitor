# Windows 一键启动：免管理员自动注册（2026-10-09）

> 承接《单文件一键启动与面板守护-2026-10-08》。上一版把 quant 协议/守护任务的注册放在管理员安装器里，用户没跑导致页面按钮失效；本版改为后端启动时自动注册，免管理员。

## 为什么按钮会“点了没反应”
- 浏览器安全沙箱禁止网页（file:// 或 http）里的 JS 直接启动本机程序。
- 唯一合规桥接是自定义协议 `quant://start-backend`，但它必须先在 Windows 注册表登记，否则浏览器静默失败（file:// 下连“是否打开外部程序”的提示都不会弹）。
- 旧“重新连接”只做 `location.reload()`，后台没起时刷新后仍是遮罩。

## 本版机制
1. `scripts/win_self_register.py`（仅 `sys.platform=='win32'`，其它平台 no-op）：
   - `reg add HKCU\Software\Classes\quant ...\shell\open\command` = `wscript.exe "<root>\scripts\panel_guard.vbs" "%1"`（HKCU 普通权限即可，无需管理员）；
   - 生成 UTF-16 XML 并用 `schtasks /create /tn QuantPanelGuard /xml ... /f` 建当前用户任务：LogonTrigger 延迟30秒 + 每5分钟重复、RunLevel=LeastPrivilege、InteractiveToken；失败静默（开机交易任务 QuantDailyTrade 的 step_restart_panel 仍会起面板）；
   - 结果追加到 `logs/self_register.log`；任何异常不阻断面板。
2. `api/real_data_server_v2.py` 的 `__main__`：app.run 前把 scripts 加入 sys.path 并调用 `win_self_register.self_register_if_windows(root)`。
3. 每天自动任务 `git reset --hard origin/master` 拉新代码、step_restart_panel 重启 run_simulation.py（其子进程跑 real_data_server）→ 启动即自动注册，无需人工。

## 前端（index.html 未连接遮罩）
- 绿色按钮：隐藏 `<iframe src="quant://start-backend">`（3秒移除，失败回退 location.href）→ 每1.5秒轮询 `/api/v1/strategies?data_mode=live` → 30秒内成功自动 `location.reload()`；超时显示引导块。
- 三个真链接（`<a class="ce-link">`）：
  - 启动器文件：`dir + encodeURIComponent('启动AI量化面板.bat'|'.command')`，dir 取当前 index.html 所在目录；浏览器对可执行脚本可能改为下载，点下载项运行一次即可；
  - 实盘：`http://localhost:8000/?data_mode=live`（target=_blank）；
  - 模拟：`http://localhost:8000/?data_mode=simulator`（target=_blank）。
- “我已启动，重新连接”→ `reconnectBackend()`：显示“正在重新连接…”，轮询18秒，失败给明确提示。

## 与管理员安装器的关系
- setup.py / install_v9.bat 里仍保留 HighestAvailable 版同名任务与协议注册（幂等 /f 覆盖）；运行时普通权限版与管理员版同名共存、互相覆盖，无需特殊处理。
- 若普通权限建守护任务失败：HKCU quant 协议仍会成功（按钮可用），且开机交易任务本就会重启面板，不影响主路径。
