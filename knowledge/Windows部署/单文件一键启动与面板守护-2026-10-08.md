# 单文件一键启动后台 + 面板开机守护（2026-10-08）

目标：只打开 index.html 一个文件；后台没开时在页面里点按钮即可启动，无需第二个文件。模拟盘、本机真实撮合，不接券商账号。

## 为什么不能让网页按钮直接启动程序
浏览器安全沙箱禁止网页运行本机程序。用两条合规手段达成体验：
1. 开机守护让后台一直在（主路径）；
2. 一次性注册 quant:// 专用链接，页面按钮经它唤起本机启动器（兜底）。

## Windows 一次性安装（仅一次，需管理员）
1. 右键 `install_v9.bat` → 以管理员身份运行（幂等，可重复跑）。
   它会新增：面板守护计划任务 QuantPanelGuard（登录后30秒起、每5分钟确保后台在听、崩溃自愈），以及 quant:// 专用链接注册。
2. 首次在页面点"▶ 一键启动数据后台"时，若浏览器弹"是否打开外部程序"，点允许并勾选"始终允许"。

## 以后每天（零操作）
- 开机登录约30秒后后台自动在；双击项目里的 index.html 直接进面板。
- 万一后台没在：index.html 页面点绿色"▶ 一键启动数据后台（启动后自动连接）"，会自动启动并刷新，不用去找别的文件。

## 手动"拉取最新代码"（git pull）什么时候才需要
交易日开机的自动任务已经会自动拉取，通常不用手动。只有想立刻拿到刚发布的新版本时：
1. 打开「Git Bash」；
2. 输入 `cd /d/quant-monitor` 回车；
3. 输入 `git fetch origin master` 回车；
4. 输入 `git reset --hard origin/master` 回车（本机不改代码，用 reset 最稳、无冲突）；
5. 关闭窗口，刷新浏览器。

## macOS

- quant:// 已通过 scripts/register_quant_protocol_mac.sh 注册（QuantLauncher.app）；页面按钮同样可用。
