# 成交可靠性监督器与面板健康灯（2026-10-08）

> 位置：knowledge/Windows部署。关联：实盘运行架构与自动化边界-2026-10-06.md、windows-deployment-runbook.md。
> 适用：Windows 交易日 13:00–17:00 开机自动成交；Mac 设计制作 + 读数据仓库展示。全程模拟盘、本机撮合，不接券商。

## 解决什么问题
10-08 首日暴露：①onlogon 任务在睡眠解锁/未重新登录时不触发，下午无自动成交；②东财行情节点 502 时，旧逻辑用历史收盘价兜底成交（旧价，作废）；③一轮失败即终止、无重试；④Mac 面板看不到成交健康状态。

## 组件与职责
| 组件 | 位置 | 职责 |
|---|---|---|
| 严格行情 | run_daily_engine.py `fetch_realtime_quotes` | 东财→腾讯→新浪当日真实价，先到先得补缺；无历史价兜底 |
| 成交闸门 | run_daily_engine.py `run_once` | 缺必需标的真实价→missing_price，撮合前返回、不动账 |
| 常驻监督器 | trade_supervisor.py | 重试到成功/收盘转收盘价/17:00 红灯；单实例锁；写心跳并 push |
| 每日编排 | daily_task.py `step_run_supervisor` | 更新代码→依赖→监督器(16500s)→兜底 push→心跳→重启面板 |
| 计划任务 | setup.py | onlogon+3 / **13:05** / 15:10 / onlogon+1 四任务，/rl HIGHEST |
| 健康灯 | live_aggregator + server + data.js + index.html | 绿/黄/红三态，读 _run_logs/trade_health.json |

## 重试节奏（用户拍板）
- 第 1/2/3 次失败后分别等 2/3/5 分钟（应对开机网络、DNS 抖动）；之后固定每 10 分钟一轮，**无限重试到拿到当日真实价**。
- 15:00 后接口现价即当日真实收盘价，监督器自动转入收盘价成交（收盘补成交内置）。
- 约 16:56 收尾；17:00 仍极端失败 → pending_overnight 红灯，等次日核对（跨日自动补单暂未做）。

## 心跳字段（Mac 面板/排障都看它）
`live-data/_run_logs/trade_health.json`：status、attempt、price_sources{em,tencent,sina}、done_count/total、trades_total、pending_strategies、retry_reasons、next_retry_at、每策略 status/missing/price_source/total_asset/today_pnl。

## 升级注意（重要）
- 代码走 GitHub：Windows 每日开机 `git reset --hard origin/master` 拉新代码。
- **但计划任务变更不会随 git pull 生效**：新增 QuantDailyNoon、/rl HIGHEST 必须在 Windows 重跑一次安装器/注册段（setup.py），随后用 schtasks 回查四个任务齐全。
