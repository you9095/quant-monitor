# 2026-10-09 换方向：废弃 file:// + quant:// 启动路线，改后端同源托管 + 单一启动器

## 一句话结论
双击 index.html（file://）+ 网页内绿色按钮经 quant:// 自定义协议启动后台，这条路线连修 8+ 版（V1–V9、#49–#53）仍在 Windows 真机失败；根因是踩在浏览器两条安全红线上（file:// 连本机服务的 PNA/CORS、网页经自定义协议拉起本机程序）。用户拍板换方向后，改为业界标准形态：**Flask 后端同源托管整个前端 + 双击桌面一个图标静默起后台并自动开 http 面板**。真实浏览器全流程验证通过，提交 `f950a11`。

## 为什么旧路线必然失败（根因）
- 用户在 Windows 双击 update-and-start.bat 已看到 `[OK] Panel is ready`，数据仓库心跳证明 Windows 22:10 已更新到 `4caff67`、后台在线；但双击 index.html 仍停在"数据后台没有运行"遮罩，点绿色按钮"闪几下就关闭"。
- Mac headless Chrome 测过的 PNA/CORS 修复（OPTIONS 204 + `Access-Control-Allow-Private-Network: true`）在 **Windows 桌面 Chrome/Edge 真机不生效**——无头浏览器不强制桌面版的全部 file:// 安全策略，实验室通过 ≠ 真机通过。
- 两件事都踩红线：
  1. `file://` 页面 fetch `http://localhost:8000` 属于"公网环境页访问私有网络"，桌面浏览器逐版本收紧，需用户手动改 flags，不可控；
  2. 网页点按钮启动本机程序（quant:// 自定义协议 + 注册表 + 隐藏 iframe），浏览器会拦截/闪烁/不回跳，且注册链路在普通权限下脆弱。
- 教训：**不要和浏览器安全模型对抗**。本机服务的标准交付形态就是"起一个本地 HTTP 服务，浏览器访问 http://localhost:端口"，前端与 API 同源，天然没有跨域。

## 新方案（三块）

### ① 后端同源托管整个前端（任务 #54）
- `api/real_data_server_v2.py` 原本就有静态路由，但 catch-all `/<path:filename>` **无白名单**：实测源码（real_data_server_v2.py）、launch_panel.py、账本 `live-data/_account_state/*.json`、`.git/config`、setup.py、venv 配置全部 200 暴露；服务监听 0.0.0.0，同网段可达——这是严重越权读取漏洞。
- 收紧为白名单：
  - `_FRONT_PAGES`：index / trades / reconciliation / pnl_history / review / P3_STATUS 六个 .html；
  - `assets/` 下仅白名单扩展名（.html/.js/.mjs/.css/.json/.png/.jpg/.gif/.svg/.ico/.webp/.woff2/.ttf/.eot/.map/.txt，排除 .bak）；favicon；
  - `_FORBIDDEN_PREFIX`：api/ scripts/ live-data/ .git/ venv/ strategies/ signals/ data/ config/ tests/ memory/ work_logs/ project_memory/ knowledge/ docs/ references/ audit/；含 `..` 一律 abort(404)。
- 前端同源逻辑早已就绪（common.js `API_BASE` 在 http 下为空串，data.js/data_v2.js 在非 file 下用相对 `/api/v1`），http 访问零跨域。
- curl 复测：前端页面 + assets 全 200，health/strategies/overview（live + simulator）全 200，全部越权探测全 404。

### ② 单一启动器：双击桌面图标 → 静默起后台 → 自动开面板（任务 #55）
- `scripts/launch_panel.py` 新增 `--open`：幂等（health 已通则直接开浏览器）、新拉起/抢锁失败都会 `wait_healthy()` 就绪后 `open_in_browser()` 打开 `http://localhost:8000/`（Windows os.startfile / Mac open / Linux xdg-open，webbrowser 兜底）。**不带 --open 的 QuantPanelGuard 守护任务绝不弹浏览器**。
- 新增根目录 `AI量化面板.vbs`：纯 ASCII、CRLF、`ws.Run cmd,0,False` 隐藏窗口，调 `venv\Scripts\pythonw.exe scripts\launch_panel.py --open`（无黑窗；无 venv 回退 pythonw）。
- `scripts/win_self_register.py` 新增 `_create_desktop_shortcut()`：用 PowerShell `-EncodedCommand`（UTF-16LE base64）传中文名规避 GBK 雷区，在桌面建"AI量化面板.lnk"（TargetPath=pythonw、Arguments=`launch_panel.py --open`、WindowStyle=7 最小化、幂等），后端启动自注册时一并创建，写 logs/self_register.log。
- `update-and-start.bat` 末尾改 `launch_panel.py --open`，成功提示指向桌面图标；Mac `启动AI量化面板.command` 同样改 --open。
- 三文件 py_compile 通过；VBS/BAT 经 Python 严格校验纯 ASCII、VBS CRLF（V1–V8 bat 闪退根因就是 UTF-8 中文被 GBK cmd 截断）。

### ③ 遮罩/绿色按钮重构（file:// 仅作后备）
- index.html 遮罩删除 quant:// 自定义协议、隐藏 iframe、launchBackend()、启动器文件链接、授权提示。
- 绿色按钮文案"▶ 打开 AI 量化面板"，onclick=`gotoPanel()`，行为是**顶层页面跳转** `http://localhost:8000/[?data_mode=当前]`——顶层导航不受 PNA/CORS 限制，后台在跑必进面板；轮询自愈成功后也调 gotoPanel()。
- 主入口不再依赖 file://；Mac 桌面 Chrome 实测 file:// 也能直连（PNA 修复对 Mac 桌面版有效），Windows 桌面版以"桌面图标 → http"为准。

## 验证中发现并修复的 3 个 UI bug（任务 #35 范畴）
1. **模拟盘顶部 KPI 恒显示初始值**（¥60,000 / 盈亏0 / 收益0 / 总资金60,000）：根因是后端 `portfolio_summary` 的非 live 分支错调 `live_module.get_portfolio_summary()`（读真实账本），模拟盘返回初始零值；而 overview 非 live 分支的模拟汇总（88383.16/+47.31%）是对的。新增 `build_simulator_portfolio_summary()`，与 overview 同口径（信号 live_total_pnl/live_total_return，仅统计 live_days>0），返回前端期望的 total_value/total_pnl/total_return_pct/per_strategy。修复后顶部 KPI：总盈亏 +¥28,383.16、收益率 +47.31%、总资金 ¥88,383.16。
2. **模拟盘各策略卡"总盈亏金额 +0"**（收益率 +20.06%/+151.42% 正确，仅金额为 0）：卡片金额读 `portfolio_summary.per_strategy[sid].current_value`，与 bug1 同根因，后端一处修复同时解决；修复后七星卡金额 +2,005、追电 +15,141 等。实盘卡金额（-15）本就正常，未改坏 live 路径。
3. **带 `?data_mode=` 参数时点右上角切换按钮无效**：toggleDataMode() 改 localStorage 后 `location.reload()`，但 data.js 以 URL 参数为最高优先级又把模式覆盖回去。改为切换时用 `URLSearchParams` 同步重写地址栏 data_mode 再导航。回归：带参页面点切换，URL 变 ?data_mode=live、按钮变"实盘"、KPI 切换为实盘值。

## 给后续的硬性经验
- 本机数据面板：永远"本地 HTTP 服务 + 同源前端 + 一个桌面启动器"，不要再尝试让 file:// 直连或网页按钮启动进程。
- 任何"网页能做什么"以真机桌面浏览器为准，headless 通过不算数。
- 对外加静态文件托管必须白名单，catch-all 等于把源码和账本挂到同网段。
- 模拟盘 / 实盘模拟 / 回测 / UI 虚拟数据四套口径严格分离，任何金额都标数据性质；模拟盘子页面保持诚实空态，不造流水。
- bat/vbs 一律纯 ASCII + CRLF；中文用 PowerShell EncodedCommand 传。
