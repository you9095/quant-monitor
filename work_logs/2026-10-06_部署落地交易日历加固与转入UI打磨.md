## 三、数据仓库强制对齐 GitHub（commit 619baec）
`scripts/fix_and_report.py` 对已存在的数据仓库，由 `git pull` 改为 `git fetch origin master && git reset --hard origin/master`（SSH/HTTPS 通道切换保留）。定位：**GitHub 数据仓库是唯一真相源，Windows 执行端无状态、成交后当日即 push**；这样今晚归零后，Windows 开机自检强制拿到空账本，也避免本地脏文件或 pull 冲突。代码仓库侧 QuantBootCheck 本就 reset --hard，故 Windows 下次开机自动拉到含交易日历的最新代码，无需再双击。

## 五、自动化边界共识（回答"为何 V9 还要手动一次"）
- **引导困境 + UAC**：全新 Windows 上没有代码/Python/计划任务，"第一个自动程序"无法自己创建自己；创建计划任务等系统级操作 Windows 强制真人点一次 UAC，脚本不能也不应静默绕过。故"一次右键管理员"是整台机器一生一次的点火，V1–V9 的反复点击是部署踩坑期的特殊状态，非常态。
