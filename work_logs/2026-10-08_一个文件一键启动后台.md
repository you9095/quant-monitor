# 2026-10-08 一个文件解决全部：页面内一键启动后台 + 面板开机守护

> 任务 #51，commit `6587173`。用户痛点：不接受"后台没开还要去双击第二个启动器文件"，要求打开 index.html 一个文件解决所有问题。全程模拟盘、本机真实撮合，不接任何券商账号。

## 一、技术边界（必须讲清）
- 浏览器安全沙箱禁止任何网页（file:// 或 http）里的 JavaScript 直接启动本机程序；软链接、普通超链接、按钮都绕不过。
- 能做到"只打开 index.html、在页面里点一下就启动后台"的合规桥接只有两类：
  1. **自定义 URL 协议 quant://**（与点击邮件链接唤起邮件客户端同机制）：一次性向系统注册协议处理程序，页面按钮 `location.href='quant://start-backend'` 即由系统调起本机启动器。
  2. **后台开机自启 + 崩溃自愈**：让"后台没开"几乎不发生，双击 index.html 永远直连（主路径）。
- 系统级注册（计划任务/注册表/LaunchServices）无法靠 git pull（拉取最新代码）完成——那只是替换文件，无权改操作系统配置，任何系统都要求至少一次提权运行；之后永久生效、日常零操作。

## 二、实现
### Windows（实盘机）
- `scripts/panel_guard.vbs`：静默守护/协议处理（wscript 无窗），检测 8000 不在听则调用 start_panel_quiet.bat；幂等。
- `scripts/start_panel_quiet.bat`（纯 ASCII）：切到项目根，netstat 检端口，不在则 `start /min venv python run_simulation.py`。
- `setup.py` 新增：
  - 计划任务 **QuantPanelGuard**（XML 导入，登录后 30 秒首次运行、之后每 5 分钟重复、HighestAvailable、IgnoreNew），保证面板开机即起、崩溃 5 分钟内自愈；
  - 注册表 `HKCU\Software\Classes\quant`（URL Protocol + shell\open\command 绑定 `wscript.exe panel_guard.vbs "%1"`，用户级无需额外提权）。
- 生效方式：在 Windows **以管理员身份重跑一次 install_v9.bat（幂等）**；之后随每日拉取自动更新脚本，无需再重装。

### macOS（设计机）
- `scripts/QuantLauncher.app`（CFBundleURLSchemes=quant，LSUIElement）：可执行脚本**立即返回**，启动动作 `nohup bash -c ... &` 完全 detach（先 launchctl kickstart，3 秒后仍无端口再 venv 直接起），避免 `open`/浏览器等待。
- `scripts/register_quant_protocol_mac.sh`：一次性 lsregister 注册（本机已执行）。
- launchd ai.quant.flask 本就 RunAtLoad+KeepAlive 常驻，双击 index.html 常态直连。

### 前端 index.html
- 未连接遮罩新增醒目绿色主按钮"▶ 一键启动数据后台（启动后自动连接）"：点击触发 quant://start-backend，并每 2 秒轮询 /api/v1/strategies，连上自动刷新（最多 ~90 秒）；首次外部程序确认提示；双击 .command/.bat 降级为"备用方式"。
- 新增 .ce-btn-primary 样式。

## 三、验证（Mac 端实测，Windows 端为静态校验）
- setup.py `py_compile` 通过；QuantPanelGuard XML 用 ElementTree 校验良构，Interval=PT5M、Command=wscript.exe、Arguments/WorkingDirectory 正确。
- vbs/bat 字节级校验纯 ASCII（无中文，规避 V1–V8 编码闪退）。
- Mac 端到端：launchctl bootout 停服确认 8000 无监听 → `open -g quant://start-backend` → **8 秒后台被拉起、health=200** → trap 自动 bootstrap 恢复 launchd 常驻（最终 PID 76759、health 200）。
- 遮罩截图：references/verify-2026-10-08-one-click/overlay_start_button.png（file:// 后台停时显示绿色一键启动按钮）。
- 教训：首版 handler 同步等待启动导致 `open` 挂起；改"立即退出 + detach 后台启动"后通过。测试脚本必须带 trap 保证恢复常驻，避免把真实后端留在停止态。

## 四、用户最终操作模型
- 一次性（仅 Windows 需要）：管理员重跑一次 install_v9.bat，注册守护任务 + quant 协议。
- 以后每天：开机后台自动在 → 双击 index.html 直接进；极端情况下页面里点绿色按钮即可，全程不碰第二个文件。
- git pull（拉取最新代码）日常由交易日自动任务完成；想立刻更新才手动：Git Bash 里 `cd /d/quant-monitor` 回车、`git fetch origin master` 回车、`git reset --hard origin/master` 回车。
