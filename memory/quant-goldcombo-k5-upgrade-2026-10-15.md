# 记忆：黄金组合跨资产策略升级（k5）+ 前端 bug 修复（2026-10-15）

- **用户铁律（最高优先）**：黄金组合从来不是"单做黄金趋势"，所有策略必须多资产；拒绝简单通用版；花大量精力做 v1–v25 回测就是要更优结果，更优成果必须用上。
- **新策略 k5（已上线）**：200 日趋势过滤 + 120 日风险调整动量 top5 + 逆波动率 cap40% + 8% 止损；13 只跨资产池。回测全期年化 17.9%、夏普 1.26、最大回撤 -11.2%；样本外（24-07~26-08）年化 26%、夏普 1.40（比样本内好、无过拟合）；9 组参数稳健。V24 基准仅年化 1.38%/夏普 0.29。
- **迭代关键**：v1-v3 用 60/120 日趋势，回撤 -36~-44%（慢熊反弹被假突破 whipsaw + 高波动追高死扛）；**200 日趋势是转折点**（2022 反弹顶过滤掉 A股/恒科/白银，只留纳指/标普/黄金）。v5 证明止损口径不是收益来源。
- **数据口径陷阱**：新浪不复权数据把基金份额折算误算成暴跌（513100 2022-01-14 -80.5%、513500 2022-03-30 -49.2%）。需手动复权（折算日收益设 0、货币 ETF 固定 1.5%），校准腾讯前复权相关性≈1。回测框架必须复用生产 Broker 保证费用/滑点/整手/T+1 一致。
- **接入引擎**：新模块 `strategies/goldcombo/cross_asset_allocation.py`（自包含，含冷启动立即建仓）；Broker 持久化 `strategy_state`；`run_daily_engine` goldcombo 改 engine=cross_asset、hist_days=260；`market_data` 新增 `load_close_qfq_multi`（东财 qfq→腾讯 qfq）。Mac 东财 push2his 直连不通，腾讯前复权可拉 642 根。
- **goldcombo 实盘重放**：用引擎 run_once 按腾讯前复权真实价逐日重放 10-08~14（标 backfill）。10-14 总资产 10012.57（+12.57/+0.13%），持仓 513100×1300/513500×1400/513520×900，现金 945.57，3 笔买入。
- **前端 bug（5 类，已修）**：①盈亏历史策略筛选不生效（live_aggregator all_sids 误并其他策略现金）；②回撤图纵轴自动缩放让 -0.47% 视觉像崩盘（固定 0 在顶、至少到 -10%）；③三个筛选页 change 不自动刷新；④复盘页 renderSummary 崩溃 s.reduce 非数组（strategies 是 dict 不是数组）；⑤复盘页策略详情字段映射错（新 schema 在 key_metrics 下）。
- **"权益曲线无限向下"真相**：权益曲线本身正常（59,100~60,050），真正问题是回撤图纵轴误导 + 盈亏历史筛选 bug，均已修。
- **模拟盘隔离**：模拟盘 5 万本金、+18.41%、运行 166 天；实盘 1 万本金、5 天、-646.34，两者完全不同，隔离正确。
