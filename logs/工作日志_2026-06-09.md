## 踩坑记录

### 坑 1：模块导入时缓存为空
**现象：** API 返回资产 = 初始资金（无盈亏）
**根因：** `fetch_realtime_prices()` 在模块导入时执行，当时 `price_cache = {}`
**修复：** `calc_strategy_data` 开头检查缓存为空则自动获取行情

### 坑 2：今天无信号文件导致持仓为空
**现象：** `load_daily_signals()` 返回 `{}`，所有策略持仓为空
**根因：** 信号文件按日期命名（`qixing_2026-06-08.json`），今天（6月9日）无文件
**修复：** `load_daily_signals` 增加回退逻辑，自动查找最近 30 天内有信号的日期

### 坑 3：GitHub 密码登录关闭
**现象：** `git push` 提示密码认证失败
**根因：** GitHub 2021 年起关闭密码登录，必须使用 Personal Access Token
**修复：** Token 嵌入 remote URL：`https://user:token@github.com/...`
